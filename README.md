# Joshua Fields — Gameplay & Systems Design Portfolio

A static portfolio focused on senior gameplay and systems design work, including hands-on Unreal implementation, validation and production delivery.

## Local preview

From this folder:

```powershell
py -m http.server 8080
```

Then open `http://localhost:8080`.

## Deployment

The site is framework-free and has no build step. GitHub Pages can publish the repository root directly.
